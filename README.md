# Repo with my config files for NixOS with Niri

## About the dotfiles
Dotfiles configuration, for a minimal niri with waybar configuration. It also uses swaybg for the wallpaper, swaylock for the lock screen and hypridle for the idle time outs.
## **Important notes**

This dotfiles are based on my workflow and hardware, so have this is mind to make use of them. The more Important points to take a look at and customize them to your preferences are:
- Flakes hardware-configuration, I'm using the help of https://github.com/NixOS/nixos-hardware repo for a custom hardware config on my dell latitude E7240. Comment or delete the lines for this configuration on the flake.nix, or also yoy can change them to your laptop model if supported.
- Change the hardware-configuration, for the one generated by the NixOS installer by replacing the repo one with yours.
- Review the packages installed so you just keep the one you need. Also feel free to change one package with other to your likes.
